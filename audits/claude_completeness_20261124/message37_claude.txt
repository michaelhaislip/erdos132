## 2. New proved lemma (general β-identity and split lemma)

**Setup.** Let x, z be roots of unity with z ≠ 1. Put C_x = x + x⁻¹, A = C_x² + 4 − 4(z + z⁻¹), suppose α ∈ ℚ^cyc with α² = A, and set β = (C_x + α)/2.

**Identity.** β² − C_xβ = (A − C_x²)/4 = 1 − (z + z⁻¹). Therefore:
- β is an algebraic integer, since it satisfies a monic equation over ℤ[x, z];
- (β − x)(β − x⁻¹) = (1 − z)(1 − z⁻¹).

**Split Lemma.** Assume α is totally real. This is automatic when α lies in a real cyclotomic field, which is exactly the axis setting. Let π = β − x, work in any ℚ(ζ_M) containing x, z and β, and let p^k be the order of z when that order is a prime power. Suppose either:
- (i) the order of z is not a prime power, or
- (ii) complex conjugation fixes every prime of ℚ(ζ_M) above p, i.e. −1 ∈ D_p ⊂ (ℤ/M)*.

Then there is a root of unity u with β − x = u(1 − z), and

  x − x⁻¹ − u + uz + u⁻¹ − u⁻¹z⁻¹ = 0.  (6-term vanishing sum)

*Proof.*
1. β is real in every embedding, so β − x⁻¹ = π̄ in every embedding. Hence |σπ|² = |σ(1 − z)|² for every σ.
2. **Ideal equality (π) = (1 − z).**
   - In case (i), 1 − z is a unit, so π is a unit too.
   - In case (ii), (1 − z) = ∏_{𝔭|p} 𝔭^m with a uniform exponent m, because (1 − z)^{φ(p^k)} ~ (p) is Galois-stable.
   - The product ππ̄ is divisible only by primes above p, and v_𝔭(π) + v_𝔭̄(π) = 2m. Since 𝔭̄ = 𝔭, we get v_𝔭(π) = m.
3. So u = π/(1 − z) is a unit whose conjugates all have absolute value 1. By Kronecker's theorem u is a root of unity.
4. β = β̄ gives x + u(1 − z) = x⁻¹ + u⁻¹(1 − z⁻¹). ∎

The eleven curves are exactly split solutions with u a monomial in x. For example, on Z = X take β = C_x − 1, which gives u = x⁻¹.

**Corollary T (target 3).** Let e > 3 be odd with e = 3^k·f and 3 ∤ f (f = 1 allowed). If −1 ∈ ⟨3⟩ ⊂ (ℤ/f)*, then √(C² + 8) is not cyclotomic, except possibly at e = 15, which must be checked directly.

*Proof.*
1. By my Lemma A, β ∈ F ⊂ ℚ(ζ_e). Work in ℚ(ζ_{lcm(3,e)}). There D_3 = (ℤ/3^{max(k,1)})* × ⟨3 mod f⟩, which contains −1 exactly under the hypothesis. So the Split Lemma applies with z = ω.
2. Consider the minimal vanishing subsums of x − x⁻¹ − u + uω + u⁻¹ − u⁻¹ω⁻¹.
   - Minimal sums of length 4 or 5 are impossible here: 5 + 1 cannot happen, and minimal sums of length 4 do not occur among μ₆-ratios.
   - So the partitions are 2+2+2, 3+3 or 6. In the first two, the ratios within each subsum lie in μ₆.
3. **x shares a subsum with −x⁻¹.** Then x² ∈ μ₆, so e | 3.
4. **x shares a subsum with a u-term.** Write x = u^{±1}ξ with ξ ∈ μ₆.
   - Substituting gives u^{±2} = w/w̄ for w = ξ + 1 − ω, or w = ξ − 1 + ω̄ in the other sign. Both w are nonzero, because |1 − ω| = √3.
   - So u ∈ μ₁₂, x ∈ μ₁₂, and since e is odd, e | 3.
5. **The sum is minimal of length 6.** By Mann's theorem the ratios have order dividing 30. Then x² ∈ μ₃₀, so e | 15.
6. e = 5 is already excluded by my Corollary from response 35. That leaves only e = 15. ∎

## 4. Route to a full classification (your question 3)

**Proposed missing lemma (conjecture with a construction, not proved).** In the non-split case, choose a ∈ D_p with a ≢ ±1:
- a ≡ p modulo the p-free part, with the unit factor 1 at p, when p ∤ ord x;
- an inertia element otherwise.

Then:
1. σ_a(π)(1 − z) / (π(1 − σ_a z)) is a unit with all conjugates of absolute value 1, so it is a root of unity ε.
2. Its complex-conjugate relation, together with this one, is linear in (β, σ_aβ), so β can be eliminated.
3. Substituting into ππ̄ = (1 − z)(1 − z̄) gives a fixed low-degree variety in torsion variables (x, z, ε, x^a, z^a).
4. For fixed p it is a surface. For target 3 it is exactly the plane curve Γ from response 35.

If no component of this variety is a torsion coset outside the known families, then Beukers–Smyth- or Aliev–Smyth-type computation gives an effective list. The open points are:
- the coset-freeness of these varieties;
- the dependence on the target prime p;
- whether a fixed power map a works uniformly when p | ord x.
